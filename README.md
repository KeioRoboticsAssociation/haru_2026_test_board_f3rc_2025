# haru_2026_test_board_f3rc_2025
F3RC2025の基板を春ロボ2026のテスト基板に改造しました。HAL環境で動作します。
コード自体は本番環境と同じものを使用しています。

## TeamA基板
エンコーダー×3 DC×2 Servo×1 リミットスイッチ×5 のみのシンプルな構造。
ちょっとした実験に使えます。

HALサイドはDC・Servo・リミットスイッチの動作検証に使用する場合があります。
また、基板Bが使えない場合は、UART通信の最適化検証に利用する場合もあります。

## TeamB基板
エンコーダー×3 のみのかなりシンプルな構造。
測定輪の動作テストに使えます。

HALサイドはUART通信の最適化検証に利用する場合があります。
